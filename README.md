# Statistical-Factor-Modelling-for-Consumer-Insights

**Business Objective**

Consumers choose cereals based on different preferences, such as health, taste, nutrition, and convenience. However, with 25 different product attributes, it can be difficult for cereal brands to understand what actually drives customer perceptions and how they compare with competitors.

The aim of this analysis is to use Exploratory Factor Analysis (EFA) to identify the underlying factors that explain how consumers perceive cereals. By reducing 25 attributes into a smaller set of meaningful dimensions, we can understand what matters to customers, compare how 12 cereal brands are positioned, and identify opportunities for better product positioning and marketing strategies.

Exploratory Factor Analysis (EFA) reduced 25 cereal attributes into four key consumer perception dimensions: Healthful, Artificial, Family-Oriented, and Interesting. Together, these factors explained approximately 50.5% of the total variance in consumer perceptions.

The analysis was supported by:

KMO = 0.85: Indicates good suitability for factor analysis.

Bartlett's Test (p < 0.001): Confirms that meaningful correlations exist between cereal attributes.

Factor Loadings: Identified which product characteristics are strongly associated with each underlying dimension.

Perceptual Mapping: Provides a visual comparison of how the 12 cereal brands are perceived relative to competitors.
